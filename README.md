
# Финальный проект 6 спринта  

В этом файле описаны фикстуры, тесты  и вспомогательный модуль data, который помогает с тестовыми данными.

## Фикстуры: 

**browser** 
Запускает браузер, открывает стартовую страницу. Адрес страницы в модуле data.


## Папка data: 

В файле data хранятся тестовые данные для заказов(два набора данных с точками входа для каждого набора) и для проверки вопросов-ответов.
В файле urls лежат урлы страниц, которые участвуют в тестах.


## Папка helpers: 

В файле locator_maker находятся два метода, которые по входящей строке делают локаторы для поиска элементов по этой строке.


## Папка locators: 

Локаторы элементов на страницах описаны в файлах этой папки.


## Папка pages: 

Тут описаны BasePage и классы тестируемых страниц.


## Папка tests:

Здесь находятся тесты

## Тесты 

### Файл test_main_page.py

**test_question_answer_correct**

Проверка ответов на вопросы. Тест параметризован


### Файл test_order_page.py

**test_order_succesfull_order**

Проверка успешного создания заказа. Тест параметризован: Первый заказ делается через кнопку сверху, второй - через кнопку снизу. Свои наборы данных для каждого заказа.


### Файл test_logo_clicks.py

**test_scooter_logo_click_main_page_opened**

Проверка открытия главной страницы при нажатии на логотип Самоката

**test_yandex_logo_click_dzen_opened**

Проверка открытия страницы Дзен при нажатии на логотип Яндекса
